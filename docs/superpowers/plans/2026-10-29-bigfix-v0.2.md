# BigFix v0.2 ("feels right") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **Execution in this project:** tasks go to Sol (`codex-caveman` / `gpt-6.1-sol`) or DeepSeek workers. Claude briefs from this plan and reviews every task. The lead runs the game (standing permission; intro, menu and opening dock only).

**Goal:** Mouse input without drops or acceleration at any polling rate, an optional frame limiter, optional background audio, and MSAA chosen in `BigFix.ini`.

**Architecture:** Same plugin. Each feature is a hook module with a pure, unit-tested core, gated by a setting, verified-bytes checks before hooking internal addresses, plus an opt-in trace flag that logs what the in-game check needs.

**Tech Stack:** As v0.1 (C++17, MSVC x64, MinHook, doctest, pytest).

**Spec:** `docs/superpowers/specs/2026-10-29-butcher-bay-bigfix-design.md` §3 Tier 2 and §3a. Static evidence is in `research/re/v0.2-input-timing-audio-aa.md`, which supplies the RVAs and trace requests.

## Global Constraints

- Every v0.1 Global Constraint still applies (`docs/superpowers/plans/2026-10-29-bigfix-v0.1.md`): verified bytes before any write or internal hook, no LoadLibrary in DllMain, settings and log next to the plugin, and no game data in the repo.
- **New settings and their defaults:**
  - `RawMouse=1`
  - `FrameCap=0` (0 = off; otherwise a maximum FPS)
  - `BackgroundAudio=0`
  - `AntiAliasing=0` (0, 2, 4 or 8 samples)
  - Trace flags `TraceInput=0`, `TraceAudio=0`, `TracePixelFormat=0`, which are not in the shipped ini

  Add them to `src/config`, `installer/BigFix.default.ini` and the README settings table.
- **Defaults must preserve v0.1 behaviour** except `RawMouse`. Raw input only replaces motion; buttons, wheel, key bindings and the game's own sensitivity stay untouched.
- **Work on branch `bigfix-v0.2`.** Parallel workers use worktrees. Each task registers its hooks with one line in the existing wiring.

## Review Focus

1. **A 1000 Hz mouse moving fast while the game drops frames:** no lost motion, no direction flips, no runaway. Pinned in Task 1 (`raw_accumulator_survives_burst`, `overflow_batch_not_lost`).
2. **Alt-tab and focus loss with raw input on:** deltas collected while unfocused must not be applied on return. Pinned in Task 1 (`deltas_discarded_when_unfocused`).
3. **`FrameCap` below the refresh rate with vsync on, and a cap above 1000:** no stutter loop, no busy-spin above 1% CPU at idle. Pinned in Task 2 (`limiter_sleeps_not_spins`, `cap_zero_is_noop`).
4. **AA on a driver without multisample formats, or with fewer samples than requested:** fall back to the nearest available format, or none, and log it. The game must still start. Pinned in Task 4 (`msaa_falls_back_when_unavailable`).
5. **Background audio when the game is minimised with sound playing:** only secondary buffers change, and the primary buffer's flags are untouched. Pinned in Task 3 (`primary_buffer_flags_untouched`).

### Task 1: Raw mouse input
**Files:** `src/raw_mouse.h/.cpp`, `tests/unit/test_raw_mouse.cpp`, a harness under `tests/plugin/`, plus one registration line.

**Interfaces:**
- `class RawDeltaAccumulator { void add(long dx, long dy); std::pair<long,long> take(); void discard(); }`. It is thread-safe and saturates rather than overflowing.
- `void installRawMouse(const Settings&)`.

**Approach (from the RE note):**
- Register raw input for the game window, with `RIDEV_INPUTSINK` off.
- Collect `WM_INPUT` deltas in the window subclass. Window mode already subclasses the window, so share that subclass or chain to it.
- At the mouse poll `MSystem+0x9BAC0` (verified prologue bytes), replace X/Y motion in the returned DirectInput batch with accumulated raw deltas, or inject the engine motion event `0xFB` as the note specifies. Keep the buttons and wheel.
- Overflow batches must no longer lose motion.
- `TraceInput=1` logs, rate-limited: per-poll HRESULT, record count, overflow flag, the raw delta applied, and the final look values if they're reachable.

- [ ] Write the failing tests: `raw_accumulator_survives_burst`, `overflow_batch_not_lost`, `deltas_discarded_when_unfocused`, `buttons_and_wheel_untouched`, `raw_off_is_original_path`. The harness drives the hooked poll with a fake DirectInput batch.
- [ ] Implement it, then check build, ctest (with and without `RIDDICK_DIR`) and pytest.
- [ ] Commit `feat: raw mouse input replaces DirectInput motion`.

### Task 2: Optional frame limiter
**Files:** `src/frame_limiter.h/.cpp`, `tests/unit/test_frame_limiter.cpp`, plus the capture SwapBuffers hook call site.

**Interfaces:**
- `class FrameLimiter { explicit FrameLimiter(double maxFps); void waitBeforeSwap(); }`. It uses a high-resolution waitable timer (`CREATE_WAITABLE_TIMER_HIGH_RESOLUTION`), with a short spin only for the final ≤0.5 ms.
- The pure scheduling function `nextDeadline(prev, now, period)` is unit-tested with a fake clock.
- `FrameCap=0` means a no-op. Log the cap once, plus the average and 1%-low frame times every 10 s when `DumpFrameTimes=1`.

- [ ] Write the failing tests `cap_zero_is_noop`, `deadline_catches_up_without_burst`, `limiter_sleeps_not_spins`, using a fake waiter that counts calls.
- [ ] Implement it, then check the tests.
- [ ] Commit `feat: optional frame limiter`.

### Task 3: Background audio
**Files:** `src/background_audio.h/.cpp`, tests, plus a registration line.

**Approach:**
- Intercept DirectSound8 creation (`DirectSoundCreate8` import or export), then the vtable's `CreateSoundBuffer` slot (`+0x18`).
- When `BackgroundAudio=1`, OR `DSBCAPS_GLOBALFOCUS` into secondary-buffer descriptors only (not `DSBCAPS_PRIMARYBUFFER`).
- `TraceAudio=1` logs each descriptor's flags, size and format.

- [ ] Write the failing tests `secondary_gets_globalfocus`, `primary_buffer_flags_untouched`, `off_is_untouched`. The pure function is `DWORD adjustBufferFlags(DWORD flags, bool enable)`, plus a harness with a fake `IDirectSound8`.
- [ ] Implement it, then check the tests.
- [ ] Commit `feat: optional background audio`.

### Task 4: MSAA from settings
**Files:** `src/msaa.h/.cpp`, tests, plus a registration line.

**Approach:**
- Following the RE note (`RndrGL+0x4B35A/0x4B600`), before the real window's first `SetPixelFormat`, obtain `wglChoosePixelFormatARB` through a disposable bootstrap window and context.
- Choose a format with `WGL_SAMPLE_BUFFERS_ARB=1` and `WGL_SAMPLES_ARB=AntiAliasing`, matching the game's other attributes.
- Substitute that format at the game's `ChoosePixelFormat`/`SetPixelFormat` IAT calls, then `glEnable(GL_MULTISAMPLE)` after context creation.
- Fall back to fewer samples, then none, logging each step.
- Must survive borderless window handling and any window recreation.
- `TracePixelFormat=1` logs the game's requested attributes and the chosen format.

- [ ] Write the failing tests `samples_attribute_built`, `msaa_falls_back_when_unavailable`, `zero_means_untouched`. The pure function is `std::vector<int> buildAttribs(const GameRequest&, int samples)`, plus a fake chooser.
- [ ] Implement it, then check the tests.
- [ ] Commit `feat: MSAA chosen in BigFix.ini`.
