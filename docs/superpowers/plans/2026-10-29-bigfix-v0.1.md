# BigFix v0.1 (Tier 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **Execution in this project:** tasks are given to **Sol** (T3 `delegate_task`, provider `codex-caveman`, model `gpt-6.1-sol`) or **DeepSeek** workers. Claude (the lead) writes each brief from this plan and reviews every task before the next starts.

**Goal:** Ship v0.1 of BigFix: an x64 ASI plugin plus scripted installers that make the original 2004 *Escape from Butcher Bay* start reliably, borderless at native resolution, with a diagnostic log and PNG capture.

**Architecture:** A C++17 ASI plugin (`BigFix.asi`), loaded by Ultimate ASI Loader (`winmm.dll`), hooks OpenGL, user32 and kernel32 entry points with MinHook.
Every hook delegates to a **pure, separately tested function**, for example the extension filter, the mode filter, the shader rewrite and the patch verifier, so almost everything is tested offline.
Binary patches are data: per-build sites with expected bytes, verified before any write.
The installers are PowerShell (Windows) and POSIX sh (Linux/Proton/Deck), and share one JSON data file.

**Tech Stack:** C++17, MSVC (VS 2022 Build Tools, x64), CMake ≥ 3.20, MinHook (FetchContent, pinned commit), doctest (single header, MIT), stb_image_write (public domain), Windows BCrypt (SHA-256), PowerShell 7, POSIX sh, Python 3 + pytest (installer and data tests), capstone (Python, static RE only).

**Spec:** `docs/superpowers/specs/2026-10-29-butcher-bay-bigfix-design.md`. Research evidence is in `research/` (02 §B2a, §B2b, §C2, §E2.1; fingerprints in `research/fingerprints/`).

## Global Constraints

- **Target binary:** `System\Win64_AMD64\SbzEngine.exe` of EU 1.1: `SbzEngine.exe` sha256 `5056ffe030c2ba8687b032f5f2ed95b42c4814db87dec61444a6cf264deaca38`, `RndrGL.dll` `400dc6b50f65c9b884e85daeac7b1b1aaa2f19d2cbf4dbd9e597abae284ea348`, `MSystem.dll` `b59eb2cc98ea40e9a5d8d79f67027965bb4bbb8b93c9e8cea8cb46c81d689500`.
- **Reference install:** `D:\Games\Riddick`. Tests that read it take the path from env var `RIDDICK_DIR` and **skip** (not fail) when it is unset.
- **Never commit game files, game-derived shader dumps, or captures.** Fixtures derived from game data live in `%RIDDICK_DIR%\..\bigfix-fixtures\` or the ignored `local/` folder.
- **No byte is ever written unless the expected bytes match first.** Every skip is logged with its reason.
- **No `LoadLibrary`, thread joins or MinHook enabling inside `DllMain`** beyond creating hooks on already-loaded modules. Module-dependent work is deferred through a `LoadLibrary*` hook.
- **Settings and log live in the plugin's own folder** (`GetModuleFileNameW` of the ASI), never the CWD.
- **Defaults:** `TextureSizeFix=1`, `FixMiscBugs=1`, `Enable20PlusPlusAnyGpu=1`, `EyeshineFlickerWorkaround=0`, `DisplayModeFilter=1`, `WindowMode=borderless`, `CaptureKey=F12`, `CapturePng=1`. TCoRFix keys (`Fix Misc Bugs`, `Enable 2.0++ on any GPU`, `Eyeshine Flicker Workaround`, `Fix Texture Size`) are accepted as aliases.
- **Installer default:** `XR_SHADERMODE=5` (2.0) until the Tier-2 shadow fix lands.
- **Licence:** BigFix MIT. `NOTICE.md` credits TCoRFix (Nezarn, MIT), Ultimate ASI Loader (ThirteenAG, MIT), MinHook (Tsuda Kageyu, BSD-2), doctest (MIT) and stb (public domain). Files containing code derived from TCoRFix carry a header line crediting it.
- **Game runs are sparing:** only Task 12 runs the game, plus Task 6 optionally once if static RE is inconclusive. Never show captures beyond the opening dock to the user.
- **Branch:** work on `bigfix-v0.1`, branched from the current `master`. Commit after each task. Push only when the user asks.

## Review Focus

1. **Game started through `Riddick.exe`, a shortcut, or Steam with a different working directory:** settings must still load and the log must still be written next to the plugin. Pinned in Task 2 (`config_path_is_module_relative`).
2. **Unrecognised build (repack, US or RU disc, or patched by another tool):** no write at a mismatching site, the game still starts, and the log says which patches were skipped. Pinned in Task 3 (`mismatch_never_writes`) and Task 4 (binary tests against mutated copies).
3. **Monitors with very few modes (1080p60) or very many (>512, several refresh rates, duplicates), and high-DPI scaling:** the native mode must always be offered and borderless must cover the whole monitor. Pinned in Task 7 (`native_mode_always_present`, `small_list_unchanged`) and Task 8 (`borderless_rect_uses_physical_pixels`).
4. **Install paths with spaces, apostrophes, non-ASCII, under Program Files (VirtualStore), or a registry `InstallPath` missing its last character:** the installer must still find, repair and install. Pinned in Task 10 (`test_paths_with_spaces_and_unicode`, `test_truncated_installpath_repaired`).
5. **Under Wine/Proton with no `winmm` override:** the plugin silently does not load. The Linux installer must set the override or print exact Steam launch options, and the docs say "no BigFix.log = not loaded". Pinned in Task 11 (`test_prints_steam_launch_option`).

### Task 3: Fingerprints and verified patch table
