# Security policy

BigFix loads native code into the game process and its installers write to the
selected game folder. Use release archives from this repository and keep backups.
Security fixes target the latest published release; older versions have no
separate maintenance commitment.

Please report vulnerabilities through GitHub's **Security → Report a
vulnerability** on this repository, rather than a public issue. Include the
BigFix version/commit, OS, reproduction steps, expected impact and a minimal
non-game-file example. Redact personal paths and credentials. Do not upload
game binaries, cracks, saves, or the official patch.

If the private reporting button is unavailable, open an issue requesting a
private security contact **without disclosing the vulnerability**. There is no
published response-time guarantee. Ordinary compatibility bugs belong in the
bug report form.
